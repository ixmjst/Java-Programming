# Java – Exercícios Académicos

Projeto desenvolvido para praticar conceitos fundamentais e avançados de Java.

## Conteúdos abordados
- Estruturas básicas
- Programação Orientada a Objetos
- Vetores e Listas
- Enum e Composição
- Herança e Polimorfismo
- Arquivos
- Interfaces
- Streams e Lambda

## Como executar
1. Execute a classe `Main`
2. Escolha o exercício pelo menu interativo
